## 5. 拍照解题：裁剪页 + 产品化流程（最大的一条）

### 5a. 裁剪页交互
- **问题**：底部拖动要先移动一下才生效（触摸 slop / 手势冲突）。边框效果不对。
- **目标效果**：图3 的样式——四个角的粗角标 + 半透明遮罩，四边中点有拖动把手，拖动即时响应。
- **方案**：重写裁剪覆盖层为独立 Compose 组件，手势用 `detectDragGestures` 单一入口，遮罩用 `drawWithContent` 画，角标用 `Canvas` 画。先在预览页验证效果，再接入。

### 5b. 流程与接口（需要你决定后端形态）
**现状**：没有真实接口。python 脚本不是解题接口。
**两个方案**：
- **方案 A（推荐）**：在 `myconf/python/ocr` 服务里新增一组 `/photosolve/*` 接口（上传、OCR、解题、错误码），由同一个 Flask 服务提供，作为服务跑起来（不再单独跑脚本）。
- **方案 B**：把解题走客户端直接调火山/大模型接口。不推荐：密钥放在客户端，且无法统一错误码。

**接口草案（方案 A）**：
| 接口 | 作用 | 错误码 |
|---|---|---|
| `POST /photosolve/upload` | 接收压缩后的 JPEG，返回图片 id | 40003 文件不合法；42901 限流 |
| `POST /photosolve/ocr` | 按图片 id 做 OCR，返回文字和区域 | 40001 模糊/无法识别；50001 服务错误 |
| `POST /photosolve/solve` | 对 OCR 文字解题，流式返回 | 40002 题目不完整；50001 |

错误分支要求：每个错误码在手机上都有提示（A25–A29）。

**需要你确认**：A 还是 B？接口是否沿用 `app.py` 的风格（Flask + JSON）？
