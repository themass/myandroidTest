设计要点

① 顶栏从「汉堡 + 标题 + 三个含义不明的图标」改为身份区（头像 / 名字 / 在线文案 / 下拉）＋三个明确动作；语音回答是开关态用填充表达，通话是主行动用渐变圆的视觉重心，记忆与形象入口收进 ⋯。

③ 消息下方不再挂 footer 芯片，复制 / 朗读 / 分享 / 删除全部收进长按弹层，长按区比小图标大得多，误触反而更少。
④ 输入框换成对话页同款白色悬浮卡片＋圆形发送键；语音、通话离开这一行，输入区只剩「说话」一件事。
