# 陪伴教学 Demo 演示记录（v2 舞台形态）

记录模板版本：2（2026-11-25 改版：舞台 + 学生摄像头 + 导演脚本）
预期路径：Android debug 包 → 抽屉「实验室」→「陪伴教学 Demo（本地）」
复核方式：按场景「▶ 播放 / 单步 / 重置」逐步走，保存设备环境、构建提交、APK SHA-256 与结果。

## 演示边界声明

本记录只复核教学流程原型（舞台形态）。台词在 Android 客户端本地脚本中产生（与旧 C2 一字不差）；
语音使用设备系统 TTS，唇形由合成 WAV 的本机包络驱动，**不申请麦克风**；学生画面 = 本机前置摄像头
预览 + 本机人脸贴纸，**帧不落盘、不上传、不存储**；工具确认、记忆纠错只改变页面本地状态。
老师形象只用自研分层立绘 `demo-avatar-v1`（自有素材）。此记录不证明线上 agent、生产记忆、
外部工具、推送或生产模型的行为；舞台演出与 TTS 播报不是模型能力。

## 自动化已验证 / 必须真机

- **自动化已验证（JVM 测试）**：导演脚本步骤序列与台词逐字一致（`TeachingScriptTest`）；退出路无表扬/特效；表情映射与收敛（`TeachingExpressionTest`）；WAV 包络解析（`VoiceEnvelopeTest`）；构建绿 + ModuleGraphTest 绿。
