# 陪伴教学 Demo（C2）

这是内部研发评审用的**教学流程 prototype**，用于演示同一个自创角色在文字/语音呈现、记忆纠错、工具确认、AI 标识和退出中的行为边界。它不是线上 agent，也不代表线上模型、记忆服务或工具实现。

所有回复由 Android 客户端内的固定脚本生成；没有网络 API、生产模型调用、账号数据或真实用户素材。语音由设备 Android 系统 TTS 本地合成。角色仅以自创文字名「林澄」和首字图标展示，不含 Live2D、Duix、Tao、demo-avatar 或其他授权未清素材。

评分场景定义与评分标准见 [C1 评分卡](../companion-internal-teaching-eval-c1.md)。可复核演示记录见 [演示记录](./demo-record.md)。

## 启动

1. 使用仓库已有 Android 开发环境，连接设备或启动模拟器。设备需有中文系统 TTS 引擎；没有时，文本演示仍可用。
2. 构建 debug 包：

   ```bash
   ./gradlew :app:assembleChatDebug
   ```

3. 安装到已连接的设备：

   ```bash
   adb install -r app/build/outputs/apk/chat/debug/app-chat-debug.apk
   ```

   如 adb 提示签名不匹配，请先在测试设备卸载旧包再安装；不要用这个教学包覆盖其他签名的应用数据。

4. 打开应用，从抽屉的「实验室」→「陪伴教学 Demo（本地）」进入。
5. 选择「正常 / 含糊 / 情绪化 / 纠正记忆 / 退出」场景，检查预置脚本对话；点「切换文字/语音」后发送一句，角色回复会通过系统 TTS 播报。
6. 点「示范工具确认」，分别检查「取消」和「确认」。确认只改变页面上的本地演示状态，不创建真实提醒。
7. 检查每条角色回复附近的「AI 生成 · 林澄」标识，以及顶部「本地脚本」说明。选退出场景后，页面确认结束并隐藏输入框；右上角退出可随时关闭页面。

## 运行边界

- Demo 入口、Activity 和页面代码仅放在 debug 源集；抽屉入口在非 debuggable 构建中隐藏。发布变体不包含这套教学实现。
- 脚本仅对教学场景给出固定回复。输入不在脚本覆盖范围内时，不能把响应解释为线上 agent 能力。
- Demo 页面未接入真实记忆、外部工具、通知、账号、网络或线上 agent；UI 中的记忆更新和确认均为本地演示状态。
- 不向设备申请麦克风权限。语音只由系统 TTS 播报输入框对应的脚本回复。
- 关闭页面不会影响账号、会话或生产数据。

## 推荐评审顺序

按 C1 评分卡五路逐个点击场景并重置，再演示语音、工具取消/确认、AI 标识和退出。记录设备型号、Android 版本、TTS 引擎、APK SHA-256、构建提交、每路实际输入与输出，以及是否存在未覆盖分支。不要把本地脚本响应或本地确认写成线上能力已验证。
