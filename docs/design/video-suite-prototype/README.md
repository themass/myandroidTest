# 放映场 · 视频体验原型

用 Chrome 打开 `index.html`。HTML、样式、脚本和媒体均在本目录，不需要联网或安装依赖。

- 频道：浏览推荐、筛选频道、打开本地样片库。
- 视频列表：试用续播、未观看筛选、海报/列表视图。返回时恢复当前页面的筛选、视图与滚动位置；收藏与播放进度由浏览器保存（取决于浏览器的本地文件存储策略）。
- 播放：播放 12 秒无声样片，拖动时间轴，调整倍速或进入沉浸模式。字幕面板支持演示字幕，也可导入 UTF-8 SRT/WebVTT（最多 2 MB），以 ±500 ms 调整显示时间。投屏仅展示流程，不扫描或连接设备。

这是独立浏览器原型，不接 Android、本机视频库、生产数据或线上服务。样片是从封面照片制作的短动效，不是实际节目。封面来自 Unsplash，原始图片地址如下：
