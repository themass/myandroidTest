- [ ] 把设计文档与实现不一致处标记为实现缺口或过时文档，附文件/日志证据。
- **验收/验证：** 每条状态都能从当前源码、配置或运行日志追溯；未核实项明确标待核实。
- **依赖：** 无。

### A3. 任务派发与收口模板

- [ ] 给每个方向的 worker brief 使用目标、范围、交付、验证、证据、阻塞六项格式。

## 阶段 B：LiveKit

### B1. 首帧延迟定位与优化

- [ ] 用 A1 同口径对齐阶段时间戳，确认主要长尾来自握手、ASR、agent/工具还是 TTS 首帧。
- [ ] 针对证据指向的 TTS/agent 阶段提出一个最小改动并做同场景前后对比。
- [ ] 记录首音频 P50/P95、长尾样本和回滚值；不改已经通过的协议语义，除非有新的反证。
- **验收/验证：** 至少 3 次同场景复测；延迟归因有跨端证据；优化效果达到 A1 后明确的目标，未达标则保留开放并给出下一条根因假设。
- **依赖：** A1。

### B2. 空回复与故障降级

- [ ] 追踪空文本、被取消、provider timeout/error 到用户静默的完整状态流。
- [ ] 定义限次重试、用户可听失败提示和外部副作用幂等边界。
- [ ] 验证空内容、超时、provider 错误和用户打断四种路径。
- **验收/验证：** 不出现无解释静默；日志标明 session/job、失败阶段和耗时；重试不会重复收费或执行动作。
- **依赖：** A1、A2。

### B3. 自托管 ICE 与发布/回滚手册

- [ ] 按 myconf `README-livekit.md` 验证信令两跳、DNS/TLS、UDP 媒体、TURN 和 TCP fallback。
- [ ] 编写变更前检查、蜂窝冒烟、观察、回滚步骤，明确不改 8081 companion 或生产数据库的部署边界。
- [ ] 在可控环境实际验证回滚步骤；生产切换需另有明确变更授权和窗口。
- **验收/验证：** 蜂窝完整通话有客户端/服务端配对证据；实际网络路径明确；回滚可操作；文档无密钥。
- **依赖：** A1。

### B4. 并发与长会话容量

- [ ] 建立可重复负载形状，测并发、CPU/内存、连接恢复、上下文增长、provider 限流和排空。
- [ ] 根据测量给出并发能力与资源/超时调整建议。
- **验收/验证：** 报告含负载、环境、资源曲线、失败率、并发结论及回滚值。
- **依赖：** B1、B2。

### C2. 可运行教学 demo

- [ ] 让同一自创角色完成文字和语音演示；展示记忆引用/纠错、需确认工具流程、AI 身份标识和退出。
- [ ] 选用有授权的角色素材与声音；语音失败时提供明确降级。
- [ ] 写启动说明并保存可复核的演示记录。
- **验收/验证：** 新成员按说明运行；C1 场景可重复；不出现角色声称真人/有意识或情感施压；素材授权可追溯。

### C3. 中文角色回归集与舞台表现

- [ ] 记录角色卡、模型或提示词变化前后的回归结果。
- **验收/验证：** 可重复比较；特效事件可追溯；特效失败不影响对话和音频。
- **依赖：** C1、C2。

### D3. wardrobe 变体与素材验证

- [ ] 以 `wardrobe-spec.json` 登记服装、帽子、头部替换的槽位和变体。
- [ ] 为每项补齐真实素材、来源授权、参数来源、遮挡规则、适用条件和设备证据。

- [ ] 确认退出路径、隐私说明与关闭后停止处理。
- **验收/验证：** 目标设备通话不中断；低性能时有降级；完整权限与退出路径可复现。
- **依赖：** D1、D2；试衣路径还依赖 D3。
