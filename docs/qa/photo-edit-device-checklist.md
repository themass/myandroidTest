## 1. 用户反馈的五项（必测）

### 1.1 涂鸦：粗细与颜色

| # | 操作 | 期望 |
|---|------|------|
| D1 | 选「涂鸦」工具 | 出现颜色条 + 粗细滑杆 |
| D2 | 换 2 种颜色、最细/最粗各画一笔 | 笔画颜色、粗细肉眼可区分 |
| D3 | 撤销一步 | 上一笔消失 |

### 1.2 文字：粗细、颜色、位置、改字

| # | 操作 | 期望 |
|---|------|------|
| T1 | 选「文字」，输入内容确认 | 文字落在图上 |
| T2 | 在样式里改颜色/粗细（加粗） | 预览随设置变 |
| T3 | **拖动**文字到另一位置 | 松手后位置改变 |
| T4 | 选中该文字，点修改/编辑文案 | 内容可改，位置大致保留 |

### 1.3 马赛克：沿笔迹，非固定矩形

| # | 操作 | 期望 |
|---|------|------|
| M1 | 选「马赛克」，在某一区域 **手滑一道曲线** | 仅笔迹覆盖处像素化，**不是**整块长方形蒙层 |
| M2 | 换粗细再画 | 笔迹宽度随滑杆变化 |

### 1.4 调整：可关闭面板

| # | 操作 | 期望 |
|---|------|------|
| A1 | 打开「调整」（亮度/对比度/饱和度） | 出现滑杆面板 |
| A2 | 点「完成调整」或关闭等价按钮 | **面板消失**，可继续其他工具；不是一直占屏 |

### 1.5 选中与删除

| # | 操作 | 期望 |
|---|------|------|
| S1 | 画一笔涂鸦后，点选该笔迹附近 | 出现选中态/删除入口 |
| S2 | 删除 | 该笔迹消失，可撤销恢复 |
| S3 | 对文字、马赛克各重复 S1–S2 | 行为一致 |

### 1.6 草稿托盘「再编辑」（S3 新增入口）

| # | 操作 | 期望 |
|---|------|------|
| R1 | 托盘里**长按一张图片**缩略图 | 打开同一个编辑器，显示的是这张草稿的当前图 |
| R2 | 编辑后点「完成」 | 托盘缩略图**原地更新**；草稿**顺序、张数、已输入的文字都不变**（不新增一项、不重复计数） |
| R3 | 长按**视频 / 文件 / 位置**项 | **什么都不发生**（无编辑语义，不弹错误、不黑屏） |
| R4 | 编辑器里点「取消」 | 退出后托盘图片仍是编辑前的样子 |
| R5 | 连续编辑同一张两次 | 第二次打开的是第一次的结果（不回到原图）；撤销历史不跨会话残留 |
