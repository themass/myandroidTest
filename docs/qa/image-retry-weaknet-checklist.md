## 0. 前置

| # | 步骤 | 期望 |
|---|------|------|
| E1 | `adb devices` 见设备；tip 构建 chatDebug 已装 | 能进对话页 |

| E3 | 记录进页前网络为正常 | 图片正常显示（对照基准） |

## 1. 断网进页 → 失败占位（核心场景）

| # | 操作 | 期望 |
|---|------|------|
| W1 | 打开飞行模式（或 `adb shell svc wifi disable; svc data disable`），冷启动 App 进对话页 | 文字消息正常；远程图位置显示**灰底 + 破损图标 + 「图片加载失败，点击重试」**，不是一块无差别底色、也不是 0 高度塌掉 |
| W2 | 同页多张图（收纳盒 2–4 张 / 轮播 ≥5） | 每一格各自有占位；位置角标照常 |
| W3 | 点占位格（断网未恢复） | 短暂重试样式后回到失败占位；App 不崩溃、不 ANR；**还能再点**（无冷却锁死） |
| W4 | 断网状态点开查看器（多图的其它成功图进入，再滑到失败图） | 查看器同样显示占位；单击失败图 = 重试而不是关闭查看器 |

## 2. 网络恢复后重试 → 成功回到正常显示

| # | 操作 | 期望 |
|---|------|------|
| R1 | 关闭飞行模式，点失败占位 | 进入 Retrying（占位保留 + 进度样式），随后图片正常显示 |
| R2 | 成功后上下滚动列表 / 切会话再切回 | 图片仍显示（缓存新 key；不回放旧失败结果） |
| R3 | 同一消息里一张失败一张成功时只点失败那张 | 只有那一格变化 |

## 3. 签名 URL 过期（300s 寿命）

| # | 操作 | 期望 |
|---|------|------|
| X1 | 进对话页图片正常显示后，让 App 后台挂着 ≥6 分钟（或直接进页后放置 5–6 分钟不滚动），再触发该图重组（切会话回来） | 旧签名地址加载失败 → 显示失败占位 |
| X2 | 点占位 | 走 `GET /uploads/{id}` 重新签发，图片恢复 |

## 4. 慢网（弱网不等于断网）

| # | 操作 | 期望 |
|---|------|------|
| S1 | 用代理限速（推荐 `pnghd`/`trpr` 或路由器 tc；设备 Wi-Fi 走限速代理）把带宽压到几十 kbps，进含远程图的历史页 | hydration 慢但成功后图片正常；**不出现半途灰块当成终态** |
| S2 | 限速下进页使签名请求超时（连接重置/超时，异常形状） | 与断网同形：该格失败占位，其余格不受影响（本地钉过：抛异常退化为空 path，不拖垮整页） |
| S3 | 恢复带宽后点重试 | 恢复显示 |

## 5. 连点与竞态

| # | 操作 | 期望 |
|---|------|------|
| D1 | 对同一失败格快速连点 5 次 | 只发一轮重签请求（在途去重）；界面无跳动 |
| D2 | 重试进行中（Retrying）再点 | 无第二次请求；状态保持 Retrying |
| D3 | 重试成功前后快速来回切会话 | 迟到的旧请求不会把成功图翻回失败（状态机钉过；真机确认无闪回） |

| # | 操作 | 期望 |
|---|------|------|
