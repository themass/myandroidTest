### ⚠️ 离线重放的预判（跑前就要知道的）

把这两张真纸图喂**随包** `docquadnet256_trained_opset17.ort`（与端上同一模型、同一 letterbox 预处理）重放：

```
ps_paper_1（074724）rot0°:  四角 sigmoid [0.677 0.271 0.723 0.209] → 过 0.5 的只有 2 个
ps_paper_2（074755）rot0°:  [0.223 0.224 0.849 0.590] → 2 个
ps_paper_2 转 90/180/270°:  最好也只有 2 个
```

`CornerHeatmapDecoder` 的规则是**任一角 < 0.5 整次判负** → 预判真机 PS4 走不到「自动贴合（Found）」，
而是进默认框 + 黄说明。**这不一定是回归**——它指向一个待决策项：
「四角全过 0.5」对真实随手拍的纸面是否过严（3/4 过线、面积合理的框要不要接受）。
真机结果出来后按实际填表；若确认，开一条算法切片（改接受规则 + 用这两张图做样本），不擅改阈值。
