帮助中心

聊天、拍照解题、图片编辑与陪伴通话，常见问题都在这里。

主要功能

聊天

与 AI 角色连续对话，支持发送图片和附件。消息发出后若上一条还在生成，会进入排队续发，不会丢失；生成过程中可点停止，失败的消息可点重试。

拍照解题

拍题目或选相册照片，AI 识别题目并给出解答。每一次解题都保存在历史记录里，可以随时回看、继续追问。

图片编辑

支持裁剪、涂鸦、加文字、马赛克、滤镜等编辑，编辑完点保存即可写入系统相册。

陪伴通话

与陪伴角色进行实时语音通话，可随时打断对方说话（直接开口即可），通话中会显示实时字幕。

常见问题

消息发不出去，或者一直显示排队怎么办？

上一条回复还在生成时，新消息会自动排队，等上一条完成后继续发送，这是正常行为。

如果长时间没有结果：检查网络是否通畅；点该条消息旁的停止结束当前生成，再重新发送；仍失败时可点重试。

图片发不出去？

请先在系统设置里允许 uher 访问相册/相机权限。图片过大时上传会慢一些，请耐心等待；发送失败时可以重试。

拍照解题没有识别出题目？

常见原因：照片模糊、光线不足、题目只拍了一部分。建议平放纸张、对齐边框重新拍摄。识别结果可以在历史记录里找到原题再次提问。

编辑好的图片保存在哪里？

点编辑界面的保存后会写入系统相册（一般在「相机」或「图片」相册里可以看到）。未保存就退出，修改不会保留。

陪伴通话没有声音 / 连不上？

通话需要稳定网络，弱网下连接可能失败，请切换网络后重试。

确认已授予麦克风权限；通话界面如显示连接失败，挂断后重新拨打即可。

通话中可以打断对方吗？

可以。对方说话时你直接开口，系统会停下播放来听你说，这就是「随时打断」。

历史记录会丢吗？换手机能看到吗？

聊天与拍照解题的历史保存在你的账号下，登录同一账号即可查看。
