# Touch experiment model

- Original: Quaternius, [Animated Woman](https://quaternius.com/packs/animatedwoman.html), published as CC0. The author calls this a woman but does not specify a numerical age. The demo is a non-sexual head/hand interaction; this is not proof of an age assertion for other uses.
- GLB conversion: [codepawl/quaternius-glb](https://huggingface.co/datasets/codepawl/quaternius-glb/tree/main/engine/animatedwoman__Animated-Woman). Third-party conversion, not an original author file. SHA-256: `ff901c37ad591c124ef5e7a368ad310e984fba4ca7ada1527c35495e7195b36d`.
- Inspection: one skinned mesh, named head, forearm and hand joints; no mesh morph targets. The demo rotates existing joints, without claiming local soft-body deformation. Visual fidelity and actual device behavior require separate evaluation.
- Renderer: three.js, MIT; bundled license notices are in touch.bundle.js.
